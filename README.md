# playground

A collection of small, self-contained demos and experiments.

**Browse them:** https://bvandersen.github.io/playground/

Each project lives in its own folder under [`projects/`](projects/) and
never depends on another. The index page is generated automatically from
every `projects/<name>/` that has a `web/index.html` — see
[CLAUDE.md](CLAUDE.md) for the layout and rules.
